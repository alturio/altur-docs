title: "transfer_started y transfer_completed"
description: "Se activan cuando una transferencia de llamada inicia o se completa."

## Acerca de estos eventos

Los webhooks de transferencia notifican a tu sistema cuando una llamada de Altur se transfiere a un agente humano. Úsalos para mostrar contexto en tiempo real antes o justo cuando el agente reciba la llamada transferida.

## Detalles del evento

- **`transfer_started`**: Se activa cuando Altur registra que inició la transferencia.
- **`transfer_completed`**: Se activa cuando Altur registra que la llamada transferida conectó.

Ambos eventos usan el mismo formato de payload de llamada que [`on_call_end`](https://docs.altur.io/api-reference/webhooks/on-call-end), con otro `event_type` y timestamps de transferencia.

## Detalles de la solicitud

- **Método HTTP**: `POST`
- **Content Type**: `application/json`
- **Endpoint**: La URL que configures en tu integración de webhook.
- **Autenticación**: Incluye el header `X-Altur-Signature` para verificación HMAC.

### Campos de transferencia

| Campo                     | Tipo       | Descripción                                                        |
| :------------------------ | :--------- | :----------------------------------------------------------------- |
| `event_type`              | `string`   | `transfer_started` o `transfer_completed`.                         |
| `transfer_initiated_at`   | `datetime` | Timestamp ISO de cuando Altur registró el inicio de transferencia. |
| `transfer_completed_at`   | `datetime` | Timestamp ISO de cuando Altur registró conexión de transferencia.  |

Los demás campos coinciden con el payload de llamada de [`on_call_end`](https://docs.altur.io/api-reference/webhooks/on-call-end).

## Respuesta esperada

Tu endpoint debe responder con 200 OK para confirmar recepción. Para el comportamiento de reintentos, consulta la [Retry Policy](https://docs.altur.io/api-reference/webhooks/overview#delivery-retry-policy).

## Caso de uso

Cuando recibas `transfer_started` o `transfer_completed`, busca la llamada por `id` o la conversación por `thread_id` y muestra el transcript, contexto del usuario y datos de campaña al agente humano que recibe la llamada.
