## About These Events

Transfer webhooks notify your system when an Altur call is handed off to a human agent. Use them to give your agents real-time context before or as they receive the transferred call.

## Event Details

- **`transfer_started`**: Triggered when Altur records that the transfer handoff started.
- **`transfer_completed`**: Triggered when Altur records that the transfer leg connected.

Both events use the same call payload shape as [`on_call_end`](https://docs.altur.io/api-reference/webhooks/on-call-end), with a different `event_type` and transfer timestamps.

## Request Details

- **HTTP Method**: `POST`
- **Content Type**: `application/json`
- **Endpoint**: The URL you configure in your webhook integration settings.
- **Authentication**: Includes the `X-Altur-Signature` header for HMAC verification.

For `transfer_started`, `event_type` is `transfer_started` and `transfer_completed_at` is usually `null`.

### Transfer Fields

| Field                     | Type       | Description                                                        |
| :------------------------ | :--------- | :----------------------------------------------------------------- |
| `event_type`              | `string`   | `transfer_started` or `transfer_completed`.                        |
| `transfer_initiated_at`   | `datetime` | ISO timestamp when Altur recorded the transfer handoff starting.    |
| `transfer_completed_at`   | `datetime` | ISO timestamp when Altur recorded the transfer leg connecting.      |

All other fields match the [`on_call_end`](https://docs.altur.io/api-reference/webhooks/on-call-end) call payload.

## Response Expectations

Your endpoint should return a 200 OK status code to confirm receipt. For retry behavior, see the [Retry Policy](https://docs.altur.io/api-reference/webhooks/overview#delivery-retry-policy).

## Example Use Case

When you receive `transfer_started` or `transfer_completed`, look up the call by `id` or the conversation by `thread_id` and display the transcript, end-user context, and campaign data to the receiving human agent.
