## About This Event

The `transfer_started` webhook is triggered when Altur records that a call transfer handoff has started. Use it to prepare real-time context for the human agent who may receive the transferred call.

## Event Details

- **Trigger**: Automatically triggered when the transfer handoff starts.
- **Purpose**: To notify your backend or CRM before the human transfer leg connects.

## Request Details

- **HTTP Method**: `POST`
- **Content Type**: `application/json`
- **Endpoint**: The URL you configure in your webhook integration settings.
- **Authentication**: Includes the `X-Altur-Signature` header for HMAC verification.

### Transfer Fields

| Field                   | Type       | Description                                                     |
| :---------------------- | :--------- | :-------------------------------------------------------------- |
| `event_type`            | `string`   | `transfer_started`.                                             |
| `transfer_initiated_at` | `datetime` | ISO timestamp when Altur recorded the transfer handoff starting. |
| `transfer_completed_at` | `datetime` | Usually `null` for this event.                                  |

All other fields match the [`on_call_end`](https://docs.altur.io/api-reference/webhooks/on-call-end) call payload.

<Note>
  The payload describes the call at the moment of the transfer: `status` is
  `in-progress`, `answered_by` is `human`, and `ended_at`, `ended_by`, `ended_reason`, `duration` and
  `billed_duration` are `null`. The `transcript` contains the messages Altur has
  received up to the transfer; the last few lines spoken right before the
  transfer may occasionally be missing. Use `on_call_end` for the full
  transcript. The `end_user` and `campaign_user` objects reflect their values
  when the event is sent.
</Note>

Transfer webhooks do not support filters.

## Response Expectations

Your endpoint should return a 200 OK status code to confirm receipt. For retry behavior, see the [Retry Policy](https://docs.altur.io/api-reference/webhooks/overview#delivery-retry-policy).
